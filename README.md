# WaveCraft

WaveCraft is a full-stack e-commerce web application developed as an assessment project. It is built using the MERN stack and provides users with a simple platform to browse, search and purchase premium audio products such as headphones, speakers and earbuds.

The project focuses on creating a clean user interface, secure authentication and a responsive shopping experience.

## Features

- User registration and login
- Google Sign-In
- JWT based authentication
- Product browsing and searching
- Category wise product listing
- Shopping cart
- Responsive design
- Dark and Light mode
- Admin product management

## Tech Stack

Frontend
- React.js
- Tailwind CSS
- React Router
- Axios

Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/WaveCraft.git
```

Move into the project folder

```bash
cd WaveCraft
```

Install frontend dependencies

```bash
cd frontend
npm install
```

Install backend dependencies

```bash
cd ../backend
npm install
```

Create `.env` files for both frontend and backend and add the required environment variables.

Run backend

```bash
npm run dev
```

Run frontend

```bash
cd ../frontend
npm run dev
```
